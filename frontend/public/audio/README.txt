NeuroNest Audio Pack

These audio assets were procedurally synthesized for the NeuroNest project.
They are original generated sounds, not recordings of copyrighted songs.

Files:
- om.wav       Gentle OM-style resonant tone
- deep-focus.wav / deep-focus naming is represented by deep-focus.wav
- study-beats.wav
- nature.wav
- lofi.wav
- piano.wav
- ambient.wav

To use in the React app:
public/audio/<filename>.wav

The OM file is an OM-style synthesized tone, not a human devotional recording.
